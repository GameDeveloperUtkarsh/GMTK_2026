# The House That Eats Letters

> **Some houses keep secrets. This one eats Letters.**

A first-person puzzle game where **language shapes reality**.

Every object in the house has a name. Delete a letter, and **every object containing that letter disappears**. With only a limited number of deletions available, every choice matters.

Developed for **GMTK Game Jam 2026** with the theme **"Count Down."**

---

## Gameplay

Your goal is simple: **escape the house.**

To do so, you'll need to think carefully about which letters to erase. A single deletion can remove multiple objects, opening new paths—or accidentally destroying something you'll need later.

The game is built around experimentation, planning, and understanding how words affect the world.

---

## Features

- 🧩 Unique letter-deletion puzzle mechanic
- 🏠 First-person puzzle exploration
- ⏳ Limited deletion budget
- ↩️ Undo system
- 📖 Deletion history log
- 🎒 Inventory and equipped item mechanics
